Task 6: Backup and Restore
Use mongodump and mongorestore to complete the following steps:
1. Back up company_advanced to company_advanced.archive using gzip.
2. Restore it into a new database named company_advanced_restore .
3.. Verify the restored collection counts.
Important: Restore into the new database only. Do not overwrite the working database.

Back up company_advanced with gzip
>> mongodump --db=company_advanced --archive=company_advanced.archive --gzip

Restore it into a new database named company_advanced_restore .
>> mongorestore --archive=company_advanced.archive --gzip \
  --nsFrom="company_advanced.*" \
  --nsTo="company_advanced_restore.*"


Verify the restored collection counts.
>> use company_advanced
>> db.employees.countDocuments()
>> db.departments.countDocuments()
>> db.sessions.countDocuments()

>> db.employees.find()
